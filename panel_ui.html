📖 DownloadStack 3D OS 使用教程
7 大工坊全指南 · 全网搜歌 · 开源声音克隆 · 排错速查（按 Esc 关闭）
1 · 7 大专属工坊（每个面板都有独立 3D 动效与输入框）
✦ 控制台（双模式直投/搜歌 + 最近成品秒开舱 + 四大 3D 硬件台）· ⚡ 队列（轨道雷达 + 快速入队）· 🌐 AriaNg（光速同源直投）· 🧲 磁力（磁力秒解/修 DHT）· 🎬 视频（全平台直下 + 2x 超分）· 🎵 音乐（全网任意搜歌无损下）· 🎙️ 声音克隆（F5-TTS 本地 GPU 克隆 + 神经配音）。
2 · 所有下载与合成均支持「📁 选目录」
每个工坊输入框旁都配有系统原生 「📁 选目录」 按钮，点击即可把视频、歌曲、种子或克隆语音保存到任意盘符与文件夹。
🎵 全网任意歌曲检索 & 无损下载
1. 进入顶部 「🎵 音乐」（或在主页切换「🎵 搜歌直下」），输入任意歌名、歌手或歌词片段回车。
2. 支持 全网聚合 / 网易云 / B站 / YouTube Music，可选 MP3 320K / FLAC 无损 / WAV / M4A，自动内嵌封面和歌手元信息。
3. 点击每首歌右侧「⬇ 下载」，完成后自动载入右侧与底部 Hi-Fi 试听台，随时播放。
🎙️ 开源 AI 声音克隆（F5-TTS + 外部 API + 神经配音）
1. 本地零样本真克隆（F5-TTS · MIT 开源）：点右上「⚡ 一键部署 F5-TTS (CUDA)」，会在独立 .venv-voice 中自动装好 PyTorch CUDA + F5-TTS（绝不污染主环境）。部署完上传 3~15 秒人声或点「🎙️ 麦克风录制」，输入任何台词即可克隆任意人的音色！
2. 外部开源 API 模式：如果你本机已启动 CosyVoice 3 / GPT-SoVITS / Fish Speech / Chatterbox API，填入地址即可直连调用。
3. ⚡ 神经配音即用：无需等模型部署，内置 12 款高拟真中文/方言/英/日声线，1 秒立即可出片。
